# Adelfos Marketing Website

This bundle contains the original project source and the successful production build.

## Deploy the built website
Upload the contents of `frontend/dist/` to a static host (Netlify, Vercel static output, Cloudflare Pages, S3, etc.).

## Run from source
The frontend uses Yarn 1.x and Create React App/CRACO. From `frontend/`:

    yarn install
    yarn start

Build:

    yarn build

The generated site can be served from `frontend/build/` (or the existing `frontend/dist/` build included here).
